# ETS Data Platform

> Enterprise Education Data Platform built with FastAPI, PostgreSQL, MongoDB, Neo4j and PySpark.

---

# 📖 Overview

ETS Data Platform là nền tảng quản lý dữ liệu giáo dục được xây dựng theo kiến trúc **Polyglot Persistence**, kết hợp nhiều loại cơ sở dữ liệu nhằm tối ưu cho từng nghiệp vụ.

Dự án hướng tới mô hình doanh nghiệp, đáp ứng các yêu cầu:

- Quản lý dữ liệu tập trung
- Chuẩn hóa dữ liệu
- Metadata Management
- Data Validation
- ETL Pipeline
- Graph Relationship
- Dashboard quản trị
- RESTful API
- Khả năng mở rộng theo Microservice

---

# 🎯 Objectives

Mục tiêu của dự án:

- Xây dựng hệ thống quản lý dữ liệu quy mô lớn
- Thiết kế kiến trúc Polyglot Persistence
- Tối ưu hiệu năng lưu trữ
- Quản lý Metadata độc lập
- Chuẩn hóa dữ liệu trước khi lưu
- Hỗ trợ ETL với PySpark
- Quản lý quan hệ dữ liệu bằng Neo4j
- Phát triển REST API bằng FastAPI
- Xây dựng Dashboard hiện đại bằng React

---
